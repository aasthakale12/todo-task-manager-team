# Smart Task Manager

Smart Task Manager is a web-based task management application developed using Agile Scrum practices. The project is designed to help users create, organise, prioritise, and complete tasks efficiently through an interactive and user-friendly interface.

## Project Objective
The objective of this project is to build a smart and practical task management system while demonstrating iterative software development through multiple Agile versions.

### Core Features
- Add a task

## Agile Workflow
This project follows Agile Scrum practices to support iterative development and team collaboration.

- Features are written as user stories
- Work is managed through a GitHub Project board
- Tasks move through Product Backlog, Sprint Backlog, In Progress, Review, and Done
- Each version adds a clear improvement over the previous version
- Pull requests and commits are used to track team contributions

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-link>
   ```

2. Open the project folder.

3. Run the application by opening `index.html` in a browser.

## Usage
The application allows users to manage daily tasks through a browser-based interface.

- Add a new task using the input field
- Mark tasks as completed
- Delete tasks that are no longer needed
- Edit existing tasks in Version 3
- Search and filter tasks in Version 3
- View task statistics from the dashboard in Version 3

## Version History

### Version 1 – Initial Prototype
Version 1 delivered the basic working prototype of the Smart Task Manager.

**Features included**
- Add a task
- Delete a task
- Mark a task as completed

### Version 2 – UI and Usability Improvements
Version 2 focused on improving usability and interface quality while keeping the Version 1 functionality.

**Features added**
- Improved visual layout of tasks
- Better button and input styling
- Validation to prevent empty task submission
- Empty state message when no tasks are available
- Responsive design improvements for different screen sizes

### Version 3 – Advanced Task Features
Version 3 enhanced the application with more advanced task management functionality.

**Features added**
- Edit task functionality
- Search tasks using a search bar
- Filter tasks by All, Active, and Completed
- Add and display task priority
- Show dashboard statistics for total, completed, and pending tasks

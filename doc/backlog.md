# Product Backlog

## Project Overview
This backlog documents the major user stories, priorities, and acceptance criteria used to guide the development of the Smart Task Manager. The final project scope was delivered through four versions, with Version 4 serving as the final productivity-focused enhancement.

---

## Completed Versions Summary

### Version 1 – Initial Prototype
**Completed Features**
- Add a task
- Delete a task
- Mark a task as completed

### Version 2 – UI and Usability Improvements
**Completed Features**
- Improved task layout
- Better button and form styling
- Input validation for empty tasks
- Empty state message
- Responsive interface improvements

### Version 3 – Advanced Task Features
**Completed Features**
- Edit task functionality
- Search tasks
- Filter tasks by status
- Task priority labels
- Live task statistics dashboard

### Version 4 – Smart Productivity Add-on
**Completed Features**
- Due dates for tasks
- Reminder status indicators
- Recurring task support
- Upcoming tasks panel
- Productivity analytics dashboard

---

## Final Project Epic
Extend the Smart Task Manager with productivity-focused features that improve planning, scheduling, and task visibility.

## Final User Stories

### US-01 Add Tasks
As a user, I want to add tasks so that I can create a list of things I need to complete.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can enter a task and add it to the list
- Task appears immediately after submission
- Empty tasks are not allowed

---

### US-02 Mark Tasks as Completed
As a user, I want to mark tasks as completed so that I can track what has been finished.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can mark a task as completed
- Completed tasks are visually different from active tasks
- User can undo completion if needed

---

### US-03 Delete Tasks
As a user, I want to delete tasks so that I can remove unwanted items from my list.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can delete a task from the list
- Deleted task is removed permanently from the current session
- Deleting one task does not affect other tasks

---

### US-04 Improve Task Layout and Responsiveness
As a user, I want a clean and responsive interface so that I can use the app comfortably on different devices.

**Priority:** Medium  
**Status:** Done

**Acceptance Criteria**
- Layout is visually clear and organised
- App works well on desktop and mobile screens
- Buttons and inputs are easy to use
- Empty state is shown when no tasks exist

---

### US-05 Edit Tasks
As a user, I want to edit tasks so that I can correct or update task text.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can update existing task text
- Edited task is saved correctly
- Empty edited text is not allowed

---

### US-06 Search Tasks
As a user, I want to search tasks so that I can quickly find a specific item.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- Search filters tasks based on text
- Search works as the user types
- Search updates the visible task list immediately

---

### US-07 Filter Tasks by Status
As a user, I want to filter tasks so that I can view all, active, or completed tasks separately.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can switch between All, Active, and Completed filters
- Filter changes the visible task list
- Only matching tasks are shown for each filter

---

### US-08 Track Task Priority
As a user, I want to assign priority levels so that I can identify important tasks easily.

**Priority:** Medium  
**Status:** Done

**Acceptance Criteria**
- User can assign low, medium, or high priority
- Priority is shown on each task
- Priority is visually distinguishable

---

### US-09 View Task Statistics
As a user, I want to see task statistics so that I can understand my progress.

**Priority:** Medium  
**Status:** Done

**Acceptance Criteria**
- Dashboard shows total tasks
- Dashboard shows active tasks
- Dashboard shows completed tasks
- Statistics update automatically

---

### US-10 Add Due Dates
As a user, I want to assign a due date to a task so that I can manage time-sensitive work more effectively.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can select a due date while creating or editing a task
- Due date is displayed on the task card
- Due date remains linked to the correct task
- Completed tasks retain their due date history
- Tasks without due dates still work normally

---

### US-11 Show Reminder Status
As a user, I want reminder or due-status indicators so that I know which tasks need urgent attention.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- Tasks can show statuses such as Upcoming, Due Today, and Overdue
- Status is based on the current date and task due date
- Overdue tasks are visually highlighted
- Completed tasks no longer show active reminder alerts
- Reminder status updates automatically

---

### US-12 Support Recurring Tasks
As a user, I want to create recurring tasks so that I do not need to manually recreate repeated activities.

**Priority:** High  
**Status:** Done

**Acceptance Criteria**
- User can select recurrence options such as daily or weekly
- Recurring tasks are visibly marked
- When a recurring task is completed, the next occurrence is generated
- Non-recurring tasks are unaffected
- Recurrence settings stay linked to the correct task

---

### US-13 Show Upcoming Tasks Panel
As a user, I want to see upcoming tasks in one place so that I can plan work in advance.

**Priority:** Medium  
**Status:** Done

**Acceptance Criteria**
- Upcoming panel displays pending tasks with due dates
- Tasks are shown in nearest-date order
- Completed tasks are excluded from the upcoming panel
- Panel updates automatically when dates change
- Users can still access the full task list separately

---

### US-14 Add Productivity Analytics
As a user, I want to see productivity insights so that I can understand my workload and completion progress.

**Priority:** Medium  
**Status:** Done

**Acceptance Criteria**
- Dashboard shows total tasks
- Dashboard shows completed tasks
- Dashboard shows pending tasks
- Dashboard shows overdue tasks
- Statistics update automatically when tasks change

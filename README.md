# Smart Task Manager

Smart Task Manager is a web-based task management application developed using Agile Scrum practices. The purpose of this project is to help users create, organise, manage, prioritise, and complete tasks efficiently through a simple and user-friendly interface.

## Project Objective
The main objective of this project is to design and develop a smart task management system that improves personal productivity and demonstrates iterative software development using Agile methods.

## Initial Features
- Add a task
- Delete a task
- Mark a task as completed
- Edit a task
- Assign priority to tasks

## Agile Workflow
This project follows Agile Scrum practices:
- Features are written as user stories
- Work is tracked using a GitHub Project board
- Tasks move across Product Backlog, Sprint Backlog, In Progress, Review, and Done
- Development is organised into iterative versions
